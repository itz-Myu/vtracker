# VTracker (VTube Studio API Bridge)

Кроссплатформенный (в первую очередь Linux) трекер лица и рук для VTube Studio.
Использует MediaPipe, OpenCV и WebSocket API VTube Studio для передачи мимики и жестов без использования iPhone.

## ✨ Возможности
- **Трекинг лица**: углы поворота головы, моргание, взгляд, открытие рта, брови.
- **Трекинг рук**: позиция, открытие кисти, сгибание пальцев, повороты.
- **Распознавание жестов**: 12 жестов (включая ✌️, 👌, 👍), а также двухручные жесты.
- **Интеграция с VTS**: привязка жестов к выражениям (Expressions) через алиасы.
- **Калибровка**: автоматическая калибровка лица и рук с сохранением в файл.
- **GPU-ускорение**: поддержка CUDA (NVIDIA) для MediaPipe.

## ⚙️ Требования
- Python 3.10+
- VTube Studio с включенным API (по умолчанию порт `8001`)
- Веб-камера
- (Опционально) Видеокарта NVIDIA для аппаратного ускорения
